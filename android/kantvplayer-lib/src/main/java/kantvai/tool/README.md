### Overview

integrate following Android Java libraries to this project to upgrade AndroidX and JetPack.

### RxPermissions

https://github.com/tbruyelle/RxPermissions

This library allows the usage of RxJava with the new Android M permission model.

This project has stopped maintenance.

### skinsupport

https://github.com/ximsfei/Android-skin-support

Android-skin-support is an easy skin framework to use for Android. The best case, Only one line of code to integrate the framework.

This project has stopped maintenance.
